# TaskFlow — To-Do List

TaskFlow is a simple and responsive To-Do List web application developed during my web development internship at Synent Technologies.

The application allows users to create, view, complete, delete, and manage their daily tasks.

## Features

- Add new tasks
- View the task list
- Hide and show the task list
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Save tasks with Local Storage
- Responsive design for mobile and desktop
- Success message when a task is added

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `tache.html` in a web browser.
4. Start adding and managing your tasks.
